# Complexity bounds of the repository

Generated by `make bounds-table`; edit `bounds/header.md` and `bounds/runs.json` instead (`tools/bounds/README.md`).

Each row is a bound: its shape (**Bound**, with constants ①, ②, …), then their values in each run, in bold where they differ from the previous run. The last column compares the first run with the last: ↓ all lower or equal, ↑ all higher or equal, ↕ mixed, = unchanged.

## Runs

The full descriptions are in `bounds/runs.json` (tooltips of the column titles in the HTML table).

- `thunks`: a `match` is its case combinator applied to one closure per branch.
- `env`: the case combinators take code over the environment; a `match` builds no closure.
- `selfcase`: a closed `fun x => match x with … end` is the case combinator itself.
- `argenv`: a closed function is the code of its body, with its argument as environment.
- `envfix`: fixpoints with an environment; the arguments passed unchanged stay in it.
- `asm` (reference, not compared): x86-64 instructions of the functions extracted to OCaml (`make bounds-asm`).

The section **Environment machine for L** counts the steps of an environment machine (`MachineCostModel`).

Each constant was lowered while the proof still checked: a minimum per constant, not a global optimum.

## Notation

`λn. ① +> λm. ②`: applying to `n` costs ①, then applying to `m` costs ②; the `>|` of a ground result is omitted. `n` is the value of an argument, `|x|` a length (in bits or elements), `#|x|` the size of `x`, `pot f` the bound of the applications of `f`.
